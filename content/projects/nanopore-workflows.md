# Overview

Designed and developed reproducible workflows for automated analysis of Nanopore DNA and RNA sequencing data in local and HPC environments.

# Problem

Nanopore sequencing genereates large and heterogeneous datasets requiring multi-step processing.

# Solution

Developed modular Snakemake pipelines for automated and reproducible DNA and RNA sequencing analysis, ready to run in both local settings and HPC clusters.

# Stack

Python · R · Snakemake · Apptainer · conda · HPC · SLURM · Linux · Bash · Git


# Impact

* Easier, standardized and reproducible  processing of Nanopore data.

* Suitable for small workstations and computing clusters.

* Applied on real-life biomedical projects.
